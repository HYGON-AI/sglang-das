## 升级时必须核对

1. 官方要求 Python 3.11+；旧 Python 3.10 的 pip 可能退选旧 release。HCU 独立构建需单独验证，不能认为改版本号即兼容。
2. `--enable-dp-attention` 弃用，推荐 `--attn-dp-size N`；`--dp-size` 逐步统一为模型副本数，兼容解析有明确限制。
3. `--disaggregation-decode-host-receive-threshold` 语义翻转：新默认 `1` 禁用 host receive，`0` 表示始终 host receive；旧禁用配置必须改值。
4. ChunkCache 移除及统一 radix 行为变化、图参数/后端选择、平台 wheel 版本应参考附录 Breaking Changes 全部条目。
5. 混合线性模型在 speculative+structured output 下的 Mamba committed-length 修复涉及正确性，需保留。
